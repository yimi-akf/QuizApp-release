# 趣味问答

> HarmonyOS NEXT 答题应用 · 知识 · 推理 · 脑筋急转弯

## 应用简介

「趣味问答」是一款 HarmonyOS NEXT 原生答题应用，涵盖知识型问答、推理型问答和脑筋急转弯三大题型，支持多种难度等级，配合每日一题、学习热力图、错题本等功能，让学习变得有趣。

## 主要功能

- **多种题型**：知识型问答、推理型问答、脑筋急转弯
- **多种难度**：入门、进阶、挑战，循序渐进
- **每日一题**：每天一道精选题目，保持学习动力
- **统计看板**：答题数据与正确率趋势，支持「全部 / 近 30 天 / 近 7 天」切换
- **学习热力图**：可视化记录每日学习轨迹
- **深色模式**：夜间答题更护眼，6款主题随心切换
- **收藏夹**：收藏喜欢的题目，随时复习
- **错题本**：自动记录答错的题目，针对性练习
- **检查更新**：可在应用内检测新版本（通过华为应用市场服务完成，无需额外权限）
- **数据管理**：支持数据导出、导入与一键清除
- **桌面小卡片**：连续打卡 1×2/2×2 卡片与儿童版卡片，支持多主题与深浅色即时同步

## 下载安装

前往 [Releases](../../releases) 页面下载最新版本的 `.app` 安装包。

**系统要求**：HarmonyOS NEXT（**API 24 / 鸿蒙 6.1.1**）及以上；已适配 **鸿蒙 7（API 26）**

## 版本记录

### v1.1.2

> 本次更新重点：适配鸿蒙 7；统计看板可切换时间范围；修复深色切换后桌面卡片打卡数据可能被清零的问题。

1. **适配鸿蒙 7（HarmonyOS 7.0 / API 26）**，同时保持对鸿蒙 6 的兼容，升级后界面与使用方式完全不变
2. **统计看板支持时间范围切换**：可在「全部 / 近 30 天 / 近 7 天」之间切换，卡片数值、趋势图与日期范围随之联动
3. **趋势图按自然日补零**：没有答题记录的日子也会保留槽位，选择「近 7 天」时稳定显示 7 天（此前只显示有记录的天数，可能只有 2~6 根柱子）
4. **错题本重练计入答题历史与学习热力图**：此前完全不记录，会漏掉用户真实的学习量
5. **统计页观感优化**：蓝色头部瘦身（高 267.4vp → 222.0vp，占屏高 32.8% → 27.2%）；趋势图滚动提示改为自绘指示条，停止滚动后平滑淡出，不再长时间遮挡柱体
6. **修复：切换深色/浅色后，桌面卡片的连续打卡数据可能被清零**
   卡片扩展进程在色深变更时读不到主应用的统计数据，会把「全 0」当成真实数据覆盖写入打卡快照，导致卡片显示成「未打卡 / 0 天」；现已改为只读取主应用同步的快照，从结构上消除覆盖可能
7. **修复：系统处于深色模式时，「清除本地数据」后界面会错误地变回浅色**（且需重启才恢复），现改为按「跟随系统 + 系统当前色深」重新推导
8. **修复：收藏页批量清理失效收藏时反复整份读写**，现改为一次读取 + 一次写入
9. **修复：卡片深浅色状态在备份/清除时口径不一致** —— 明确其为跟随设备系统的派生状态，不随备份迁移、也不会被清除数据抹掉
10. **答题历史上限由 50 条提升至 2000 条**，并加强数据防御：导入异常备份不会再导致热力图、统计页崩溃
11. **儿童版 2×2 卡片**：动物形象放大（70vp → 76vp）并更换更清晰的新图
12. **点击桌面连续打卡卡片改为回到首页**：此前会直接进入答题流程，现在统一回到首页，同时避免答题中途点卡片导致返回确认框误弹
13. **统计口径说明**：每日一题与错题本重练不计入统计看板的「答题次数 / 平均分 / 最高分」（避免最高分被锁死在 100、以及反复重练虚增次数），但仍计入学习热力图与连续打卡天数
14. 修复部分细节问题，提升稳定性与使用体验

15. **新增应用内「检查更新」**：「我的 → 检查更新」可主动检测新版本，发现新版会弹出应用市场的更新弹窗，点一下即可更新；应用启动后也会静默检查一次，**只有确实存在新版本时才提示**。该功能调用华为官方能力（AppGallery Kit 的 `updateManager`），**联网由应用市场服务完成，应用自身不发起网络请求、不需要任何权限**，断网时静默失败，不影响任何答题功能
16. **新增横屏支持**：折叠屏展开态等大屏可随系统自动旋转（尊重系统「自动旋转」开关）；手机等窄屏仍保持竖屏
17. **答题页横屏适配**：横屏下自动收紧间距，四个选项不再被底部按钮栏遮挡
18. **折叠屏展开态首页优化**：功能卡片不再被纵向拉伸成大片空白，内容居中、整屏观感更均衡
19. **修复直板机可能停留在横屏的问题**：改由设备形态判定 —— 直板机始终竖屏，仅折叠屏按屏幕宽度决定是否允许旋转
20. **修复「关于」页版本号显示滞后**（此前未随发版同步），并调整说明文案，明确「仅检查更新会通过应用市场服务联网」
